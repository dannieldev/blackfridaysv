# Auditoría Antislop 003: suscripciones por correo

Modalidad DESPUÉS, elegida por Danniel. Alcance: formulario, mensajes, confirmación y baja de los avisos. Se conserva el sistema visual existente.

## 1. Hard Gate

El consentimiento empieza desmarcado. Una solicitud pendiente no activa avisos ni modifica preferencias ya confirmadas. La ausencia de configuración tiene un estado explícito y bloquea el envío. No se muestran contactos, ahorros, entregas o disponibilidad inventados. La API limita solicitudes y los correos pendientes no entran en la lista activa. Los datos de suscriptores permanecen separados del catálogo público.

## 2. Purpose-Gate

Dos entradas con una finalidad concreta: seguimiento de un producto por precio objetivo y resumen por intereses. El formulario explica frecuencia, presupuesto, categorías y baja. No se impone crear una cuenta, elegir una contraseña ni aceptar el resumen general para seguir un producto. Los textos de confirmación distinguen solicitud recibida de aviso activado.

## 3. Liveliness

Se reutilizan DM Sans, lima para la acción principal, superficies y diálogo nativo del sitio. No se añaden iconos decorativos, movimiento permanente ni efectos de captación. El formulario usa una columna; categorías pasan de dos columnas a una bajo 600 px. Campos de 16 px y al menos 48 px de altura; etiquetas de checkboxes con área mínima de 44 px. El foco, Escape y retorno al disparador provienen del diálogo existente.

## 4. Craftsmanship y límites

Compilación de TypeScript, build de Vite y empaquetado del Worker comprobados. Pasan 72 pruebas: 34 de web, 11 de scrapers y 27 de suscripciones. Incluyen PostgreSQL, API con proveedor simulado, selección de precios y renderizado inicial. Contraste calculado: texto secundario/borde sobre blanco 5,76:1; error sobre blanco 7,32:1; aviso sobre su fondo 6,06:1; foco sobre blanco 5,16:1.

**No se certifica la revisión visual:** el acceso del navegador al sitio local fue rechazado por la política de la herramienta. Quedan pendientes comprobaciones reales de teclado, zoom, móvil y foco tras cerrar diálogos superpuestos. El código y el renderizado de servidor no sustituyen esas comprobaciones.

**Estado operativo:** no publicado, Resend no conectado y migración remota no aplicada por HTTP 403 de permisos administrativos. La integración queda desactivada de forma explícita. Instrucciones y límites en [suscripciones con Resend](../docs/suscripciones-resend.md).
